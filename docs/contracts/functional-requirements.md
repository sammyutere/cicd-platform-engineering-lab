# Functional Requirements

| ID | Requirement |
|---|---|
| FR-001 | The platform shall provide centrally maintained reusable CI workflows. |
| FR-002 | The platform shall execute automated application tests. |
| FR-003 | The platform shall build OCI-compatible container images. |
| FR-004 | The platform shall scan release artefacts for known vulnerabilities. |
| FR-005 | The platform shall generate an SBOM for releasable artefacts. |
| FR-006 | The platform shall cryptographically sign trusted release artefacts. |
| FR-007 | The platform shall publish immutable artefacts to an OCI registry. |
| FR-008 | The platform shall support development, staging and production environments. |
| FR-009 | The platform shall separate CI execution from deployment reconciliation. |
| FR-010 | Kubernetes deployment shall be driven through GitOps. |
| FR-011 | The platform shall support controlled environment promotion. |
| FR-012 | The platform shall verify artefact identity and integrity before trusted deployment. |
| FR-013 | The platform shall provide controlled rollback capability. |
| FR-014 | The platform shall provide application-team self-service capabilities. |
| FR-015 | The platform shall expose software-delivery telemetry. |
| FR-016 | The platform shall support versioned reusable workflow interfaces. |
| FR-017 | The platform shall provide a supported Golden Path for conventional services. |
| FR-018 | The platform shall retain auditable evidence of production promotion. |
